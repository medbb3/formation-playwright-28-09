# Jour 4 — Objectifs de la journée

1. Comprendre l'architecture MCP (client, serveur, outils) et les briques de l'écosystème Playwright dédiées aux agents.
2. Configurer `@playwright/mcp` et les agents de test Playwright dans VS Code avec GitHub Copilot ; connaître la CLI Copilot.
3. Générer des tests depuis une spécification, réparer un locator cassé, rédiger de bons prompts.
4. Pratiquer le testing exploratoire assisté et convertir des scénarios Gherkin en tests.
5. Encadrer l'usage de ces outils en contexte bancaire : risques, policy, checklist.
6. Fil rouge : 5 tests générés via MCP à partir des specs fictives, journal de génération, grille de qualité.

Outil imposé par le client : **VS Code + GitHub Copilot** (Chat, mode Agent, agents personnalisés) et la **CLI Copilot** pour le terminal.
