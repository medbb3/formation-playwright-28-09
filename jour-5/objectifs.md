# Jour 5 — Objectifs de la journée

1. Adopter un workflow Git discipliné : commandes clés, convention de commits, stratégie de branches, Azure Repos.
2. Travailler en Pull Request : template, checklist de revue QA, branch policies sur `main`.
3. Écrire un pipeline Azure Pipelines YAML pour la suite Playwright, avec cache, jobs et stages, exécution dans Docker.
4. Gérer secrets et variable groups (Azure Key Vault : mention, option de production) ; paralléliser par matrice et shards ; planifier ; poser 4 quality gates.
5. Choisir les reporters (HTML natif, résultats de tests Azure DevOps), suivre 3 KPIs QA simples, détecter la flakiness, rédiger le rapport hebdomadaire, définir la Definition of Done.
6. QCM et évaluation.

Contexte client :

- **Azure DevOps** (Azure Repos, Azure Pipelines).
- Vous travaillez dans votre propre organisation Azure DevOps gratuite.
- Les tests tournent dans Docker.
